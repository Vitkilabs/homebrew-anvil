# Vitkilabs Anvil for Homebrew

Anvil is a private, local, encrypted AI memory tool for your coding assistant.
Apple silicon (M1 or newer) only.

```
brew install --cask vitkilabs/anvil/anvil-app   # the app, with the anvil command
brew install vitkilabs/anvil/anvil              # the command line only
```

Getting started: https://vitkilabs.com/docs/anvil/getting-started
