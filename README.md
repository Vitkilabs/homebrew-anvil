# Vitkilabs Anvil for Homebrew

Vitkilabs Anvil is a private, local, encrypted AI memory tool for your coding assistant.
Apple silicon (M1 or newer) only.

```
brew install --cask vitkilabs/anvil/vitkilabs-anvil   # the app, with the anvil command
brew install vitkilabs/anvil/anvil                    # the command line only
```

The app was called `anvil-app` until October 2026; `brew upgrade` moves an
existing install to the new name.

Getting started: https://vitkilabs.com/docs/anvil/getting-started
